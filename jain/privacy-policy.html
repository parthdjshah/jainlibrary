Privacy Policy

Effective date: 24 September 2026

This Privacy Policy applies to Parth Jain Books (the "Website") and its optional Smart Annotation feature. It explains what information the Website accesses, why it is accessed, where it is stored, and how users can control it.

Smart Annotation is optional. You can read the books without connecting a Google account or a Google Sheet.

1. What Smart Annotation does

Smart Annotation lets a user select text in supported books and apply underline, bold, italic, blue highlight, yellow highlight, or green highlight formatting. The user may save these annotations to one Google Sheet selected by the user. The same selected sheet can be used for books throughout the Website.

2. Google user data accessed

When a user enables Smart Annotation, the Website uses Google's authorization services to obtain permission to work with the specific Google Drive file selected by the user through the Google Picker.

The application uses the Google drive.file scope. This scope is used to access only the specific Drive file that the user selects for use with Smart Annotation. The application does not request general access to the user's entire Google Drive or all Google Sheets.

For the selected Google Sheet, the application may:

  • read annotation records;
  • create the Annotations sheet/tab if it does not already exist;
  • write new annotation records;
  • update annotation records; and
  • remove annotation records when the user removes an annotation.

3. What annotation information is stored

To restore an annotation when the same book is opened later, the selected spreadsheet may contain:

  • the unique annotation identifier;
  • the book HTML page name;
  • the selected text;
  • text immediately before and after the selection, used to help relocate it;
  • document position information;
  • the annotation style;
  • creation time; and
  • last update time.

The Website does not require the user to enter a password into the Website.

4. Where Google user data is stored

Annotation records are stored in the Google Sheet selected and controlled by the user. The Website does not intentionally copy the contents of that spreadsheet to a Website-owned database or server.

The browser stores the selected spreadsheet's identifier and related configuration in the Website's local browser storage so that the user does not have to select the same sheet again on every book page on the same browser and device.

Google OAuth access tokens used during a browser session are handled by Google's browser authorization libraries and are not intentionally stored by the Website in its own server database.

5. How Google user data is used

Google user data is used only to provide the Smart Annotation functionality requested by the user: selecting the user's annotation spreadsheet, reading annotations, saving annotations, updating annotations, removing annotations, and restoring annotations in the appropriate book.

Google user data is not sold, rented, or used for advertising. It is not used for unrelated purposes and is not used to build advertising profiles. The Website does not use Google user data for training a general artificial-intelligence or machine learning model.

6. Sharing of Google user data

The Website does not sell or share Google user data with advertisers or data brokers. Google processes data through Google's own services according to Google's applicable terms and policies and the permissions granted by the user.

The selected spreadsheet remains subject to the user's own Google Drive sharing settings. Users should choose a spreadsheet whose contents they are comfortable using with Smart Annotation.

7. Retention and deletion

Annotation records remain in the user's selected spreadsheet until the user deletes them, removes them using the Smart Annotation interface, or otherwise changes the spreadsheet.

The Website's local browser setting containing the selected spreadsheet identifier can be cleared by clearing the Website's browser storage. The user may also change the selected spreadsheet through the Smart Annotation settings button.

A user can revoke the application's Google access through the user's Google Account security and third-party-app access controls. Revoking access prevents the Website from continuing to use the Google authorization until the user authorizes it again.

8. Website analytics

The Website may use Google Analytics to understand general Website usage, such as page visits and technical usage information. Google Analytics is separate from the Smart Annotation spreadsheet data. Smart Annotation spreadsheet contents are not sent to Google Analytics.

9. Security

The Website uses HTTPS when served from its public domain and uses Google's OAuth authorization mechanism for Google service access. No Google password is collected by the Website.

No security measure can guarantee absolute security. Users should also protect their Google Account and maintain appropriate sharing permissions for their selected spreadsheet.

10. Children's privacy

The Website is primarily a digital reading resource. Smart Annotation is not designed to require children to provide personal information. The Website does not intentionally request a child's Google password or unrelated personal information.

11. Changes to this Privacy Policy

This Privacy Policy may be updated when the Website, Google integration, or Smart Annotation functionality changes. The effective date at the top of this page will be updated when material changes are made.
